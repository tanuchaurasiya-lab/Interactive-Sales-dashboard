# Interactive Sales Dashboard

## Project Overview
This project analyzes `sales_data.csv` (`100` rows, `7` columns: `Date`, `Product`, `Quantity`, `Price`, `Customer_ID`, `Region`, `Total_Sales`) to present sales trends, customer segmentation, and product performance using **Seaborn** for statistical charts and **Plotly + Streamlit** for interactive exploration.
- **Total Revenue:** `$12,365,048`
- **Top Product by Revenue:** `Laptop` (`$3,889,210`)
- **Top Region by Revenue:** `North` (`$3,983,635`), while `West` (`$2,123,922`) has the lowest total sales
